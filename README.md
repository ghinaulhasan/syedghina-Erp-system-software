# SyedGhina ERP System — Dashboard UI

A browser-based ERP-style dashboard interface built to explore a business management layout, navigation patterns, and dashboard components.

## Interface highlights

- Sidebar navigation with active and hover states
- Dashboard card components for business indicators
- Search bar and search-results section
- Loading screen with progress presentation
- Responsive layout adjustments for smaller screens
- Three.js background effect

## Technology stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Three.js
- Google Fonts (Poppins)

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ghinaulhasan/syedghina-Erp-system-software.git
   cd syedghina-Erp-system-software
   ```
2. Open `index.html` in a modern browser or use VS Code Live Server.

Some visual assets and libraries are loaded externally, so an internet connection may be needed.

## Project note

This repository showcases a front-end ERP-style interface. Do not assume that it includes production-ready authentication, database integration, or persistent business records unless those are implemented and verified separately.
